# Respaldo del juego — 13 de octubre de 2026

Repositorio: https://github.com/yoyi9313-collab/ELCOMPANY

## Recuperar después de formatear

1. Instala GitHub Desktop o Git y clona ELCOMPANY.
2. Instala Godot 4.7.2 (versión utilizada para desarrollar el proyecto).
3. Importa `juego-maraco/project.godot` en Godot y espera la importación de los recursos.
4. Pulsa F5 para iniciar el juego.

El proyecto jugable incluye sus modelos, texturas, animaciones, escenas, código y pruebas. La versión online se conserva; consulta `juego-maraco/ONLINE_1V1.md` y `juego-maraco/README.md`.

También se incluyen las carpetas originales americano, Basic Shooter Pack, KAR98, NAZI y Toon_Soldiers_WW2_Godot, junto con los ZIP/RAR suministrados. Son recursos de origen; el proyecto usa sus propias copias dentro de `juego-maraco/assets`.

Se excluyen la caché `.godot`, registros, capturas de pruebas, archivos locales de secretos y el instalador de GitHub Desktop. Godot regenera su caché al importar. Este repositorio respalda el juego y sus recursos, no el resto del PC ni las credenciales de las cuentas.
